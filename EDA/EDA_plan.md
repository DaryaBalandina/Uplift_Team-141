# План EDA

1. **Качество данных.** Проверить размер, типы признаков, пропуски, дубли и выбросы, решить, как с ними поступать.

2. **Тритмент, таргет и общий эффект.** Посчитать доли групп и откликов, затем средний эффект: разницу долей откликов между тритментом и контролем.

3. **Проверка рандомизации.** Проверить, отличает ли классификатор на признаках датасета тритмент от контроля. При хорошей рандомизации не должен отличать.

4. **Анализ признаков.** Посмотреть распределения, корреляции между признаками и связь с таргетом, найти дублирующие и малоинформативные признаки (например, по univatiate метрикам признаков), вычистить признаки по dq проверкам (нуллы, near constant признаки). Для ключевых признаков посчитать uplift по бакетам. Может быть по каким-то одиночным признакам можно понять - у каких клиентов воздействие работает лучше или хуже.

5. **Выводы.** Определить итоговый набор признаков для моделей, схему разбиения на train/test и метрики оценки моделей.
