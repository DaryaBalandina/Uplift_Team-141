## План работы:

**1. Поиск и подготовка данных**
**2. Разведочный анализ данных (EDA)**
- Суть: понять данные и проверить, что они подходят для uplift моделирования. На двух датасетах - Hillstorm, Lenta из библиотеки scikit-uplift
- Шаги: 
  - Проверить качество данных
  - Посчитать долю тритмента, отклика и общий эффект (ATE)
  - Проверить баланс признаков между группами
  - Найти сегменты с разным эффектом.
- Результат: выводы по каждому датасету: какие признаки и метрики использовать, подходят ли данные для моделирования.

**3. Первые ML-модели**
- Суть: получить базовые uplift-модели.
- Шаги: 
- Определиться с метриками, которые мы оптимизируем.
- обучить и провалидировать на данных Lenta:
  - S-learner
  - T-lerner
  - X-lerner
- Сравнить эти три подхода.
- Результат: таблица сравнения моделей.

**4. ML-сервис**
- Суть: прототип сервиса, который по признакам клиента возвращает uplift, рекомендуемый тритмент.
- Шаги:
  - Сделать мониторинг качества модели(ей)
    - Добавить какие-то бизнесовые метрики?
  - Обернуть модель в API с поддержкой бинарного тримтмента.
  - Сделать докер образ и запустить модель на локальном сервере.
  - Сделать мониторинг сервиса

- Результат: работающий надежный прототип.

**5. Промежуточная защита**
- Результат:
  - презентация с данными, EDA, сравнением моделей, сервисом и примером работы сервиса. Можем сделать акцент на том, что мы позаботились о мониторингах.
  - Фидбэк для доработки курсовой.
